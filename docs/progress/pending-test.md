# 待测试

- [ ] 生图工作台固定使用侧边模式；模型下拉仅展示后台模型算力点中配置为图片类型的模型。比例、清晰度、质量、保持当前图一致、生成张数均复用画布图片节点的设置样式和能力限制，首次进入、新建会话或切换模型时默认使用 `21:9 / 2K / 高质量 / 1 张`，对应能力不可用时回退后台列表第一项；参考图的上传、剪贴板、素材库与结果加入入口最多保留 16 张；创建任务后保留提示词，生成按钮可继续提交任务；开始生成按钮显示按当前模型与张数计算的积分。工作流悬浮按钮首屏固定初始位置，避免服务端与客户端位置不一致导致 hydration mismatch。
- [ ] 画布图片节点再次生成时保留当前图片，将每次结果按批次保存；右上角可打开候选图片面板，选择后替换节点图片，点击画布空白处关闭面板。
- [ ] 图片节点再次生成时在原图上显示加载遮罩与进度；输入提示词时自动关闭候选图面板。候选图面板以横向流式布局展示每次生成及时间；图片节点右上角不显示“图片1”引用标签，左上角节点名称保持显示。
- [ ] 图片节点重复生成默认不把当前图作为参考，避免候选图重复；可在图像设置中开启“保持当前图一致”，主动复用当前图片作为参考。
- [ ] 画布空白处仅右击打开新建节点菜单，左键双击不触发菜单；节点和连线原有右键菜单保持不变。
- [ ] 图片节点候选批次仅在至少一张图片成功后计入右上角数量；候选窗口只展示成功图片，异步任务失败时提示生成失败。
- [ ] 图片候选窗口按最新生成批次倒序展示，保留“第 N 次生成”编号；最新批次成功后自动更新图片节点主体，手动选择候选图仍可切换至历史结果。
- [ ] 图片节点生成期间底部的提示词库、模型、图像设置、镜头控制和生成按钮均不可操作；任务成功或失败结束后自动恢复。
- [ ] 图片节点图像设置采用比例、清晰度、质量的分段选择布局，包含“保持当前图一致”和“生成张数”；画布缩放或移动时，已打开的设置面板与节点同步定位和缩放。
- [ ] 图片节点图像设置中，比例、清晰度、质量和生成张数等可点击选项均显示手型指针。
- [ ] 视频节点重复生成时不创建新节点：当前视频保留在节点底图，生成期间显示与图片候选一致的遮罩、进度与耗时；成功后自动切换为最新视频，失败时保留原视频并提示错误。
- [ ] 视频节点右上角仅在至少两批视频成功时显示候选数量；点击后按最新生成时间倒序展示成功视频，选择任一视频会替换节点内容，点击画布空白处会关闭面板。
- [ ] 视频节点设置采用时长、比例、画质、音频、码率分段布局；画质可选择 480P、720P、768P、1080P、1440P、2K、4K；“自定义时长”默认关闭，关闭时使用滑块，开启时使用输入框，设置弹窗随画布缩放同步定位和缩放。
- [ ] 管理后台模型算力点表格的所有下拉框均占满对应列宽，清空或重新勾选多选项后不会收缩；视频模型画质可配置 1440P，但新增模型默认不勾选；后台已勾选 1440P 的模型会在画布和视频创作台显示该选项，选择后，21:9、16:9、4:3、1:1、3:4、9:16 分别请求 `3360x1440`、`2560x1440`、`1920x1440`、`1440x1440`、`1440x1920`、`1440x2560`。
- [ ] 图片、视频节点在修改比例后重新生成时，会以该次比例同步更新画布中的节点展示尺寸；候选面板选择任一历史结果后，也会恢复该结果生成时的展示尺寸与比例设置，且节点中心位置保持不跳动。
- [ ] 已有图片或视频内容的节点在设置面板切换比例时，节点展示外框立即切换至对应比例；后续再次生成和选择历史候选仍维持对应尺寸。
- [ ] 图片节点的 AI 多角度弹窗中，左右角度、俯仰角度均可设置为 -90 至 90 度，并按所选方向传给生成提示词。
- [ ] 图片局部编辑支持选择笔刷颜色；所选颜色用于遮罩预览与标记参考图，笔刷大小默认值为 15px；切换颜色仅影响后续新绘制内容，已完成的笔触和画框保持原有颜色。
- [ ] 图片局部编辑的画笔旁新增“画框”模式；拖拽可绘制矩形边框，边框颜色与粗细沿用当前笔刷颜色和笔刷大小，AI 修改时以边框所圈范围为准。
- [ ] 图片局部编辑在 AI 修改旁提供“保存图片”按钮；保存后将原图与当前保留的涂鸦/画框合成为新的图片节点，自动与原节点连线并选中，不触发 AI 生成。
- [ ] 管理后台模型渠道可新增 Gemini 与火山方舟协议：Gemini 默认地址为 `https://generativelanguage.googleapis.com`，可拉取模型、测试模型；方舟默认地址为 `https://ark.cn-beijing.volces.com/api/v3`，标准 OpenAI 兼容渠道可拉取模型、测试模型。
- [ ] Gemini 渠道配置为图片或文本模型后，图片工作台与画布图片节点可完成文生图、参考图生图；画布文本节点可返回文本。Gemini 图片的比例与清晰度配置会映射到 Gemini 支持的参数。
- [ ] Gemini 图片请求将画布的像素尺寸映射为 `generationConfig.imageConfig.aspectRatio`，将质量映射为 `generationConfig.imageConfig.imageSize`；Nano Banana 2 的高质量设置应传为 `4K`。
- [ ] 画布图片节点默认使用 `21:9 / 2K / 高质量 / 1 张`；视频节点默认使用 `21:9 / 5S / 720P / 高码率`。模型能力接口未提供对应值时，自动使用接口返回列表的第一项。
- [ ] 新建图片或视频节点时，节点外框立即按照当前模型的默认比例展示；默认比例不可用时使用后台返回的第一个比例，右键新建、工具栏新建和从连线创建均一致。
- [ ] Mac 触控板手势：双指捏合仅缩放无限画布、不触发浏览器页面缩放，且缩放幅度更大；双指滚动平移无限画布；单指点击或拖动不再平移背景，节点选择和拖动由节点自身处理。
- [ ] 画布图片节点选择名称含空格或下划线的 Nano Banana 模型时，应识别为图片模型；旧节点遗留的 `local-default` 等无效渠道 ID 会自动切换为后台中实际配置该模型的云端渠道，不再提示“指定模型渠道不可用”。
- [ ] 火山方舟渠道配置为图片、文本、视频或音频模型后，画布按现有 OpenAI 兼容接口发起请求；图片参考图生成使用 JSON 图片字段。Gemini 视频和音频模型当前应提示渠道暂不支持。
- [ ] 画布视频节点提示词输入框顶部显示文生视频、图生视频、首尾帧、全能参考、视频续写五种模式，不显示视频编辑；已连线和上传的图片、视频、音频均在对应模式中回显。当前模式支持的素材正常显示，其他类型或超出数量的连线素材保留为禁用状态，不会因切换模式而删除。生成和重试只携带当前模式允许的素材。
- [ ] 视频节点中不适用于当前模式的已连接素材，保留原素材内容并以红色边框和禁用标记提示；右上角仍可点击叉号解除与当前视频节点的关联，所有参考素材的移除叉号悬停时显示手型指针。
- [ ] 文本节点直接连接图片或视频节点时，节点提示词框上方显示文本引用标签；点击标签右侧叉号会断开对应连线并移除标签，文本节点及当前手动输入的提示词保持不变。
- [ ] 点击视频节点及其他节点设置、提示词中的图片、视频、音频引用素材可打开预览：图片使用全屏查看，视频和音频在弹窗内播放；删除引用或切换引用逻辑不受影响。
- [ ] 在画布空白处按住鼠标左键拖动可显示选框并选中所有相交节点；按住 Shift 框选时可保留已有选择，空白处单击仍会关闭节点浮层。
- [ ] 单击画布空白处会关闭节点顶部工具区、提示词输入区、信息与候选面板，以及当前打开的图像处理弹窗；节点本体保持显示。
- [ ] 图片节点接收上游图片节点连线时，在提示词框上方显示参考图；前 16 张正常参与生成，第 17 张起以红色禁用状态保留并可通过右上角叉号断开连线。图片和视频节点的同类型参考素材右上角显示从 1 开始的顺序编号。
- [ ] 画布节点模型渠道自动校正或收到重复参数时，不应反复更新节点状态或出现“Maximum update depth exceeded”错误。
- [ ] 画布各生成节点的提示词输入框按 Enter 会插入换行，不会触发生成；仅点击生成按钮才会发送。输入 `@` 打开引用菜单时，Enter 仍可选择当前引用项。
- [ ] 画布视频节点请求创建失败或接口直接返回失败状态时，保留提示词输入框内容和参考素材，方便修正参数后重试。
- [ ] 画布视频节点按所选画质固定输出高度：480P/720P/768P/1080P/2K/4K 分别为 480/720/768/1080/2048/4096，再按所选比例计算宽度并传入接口；例如 21:9、720P 为 `1680x720`。
- [ ] 管理后台渠道新增“私有定制协议”配置，可选择通用协议、kk私有协议、mikito私有协议或 mikito 私有 sora 协议；视频模型创建与轮询按所选协议转换请求路径、字段和参考素材，图片、文本、音频模型仍走通用流程。
- [ ] 私有视频协议生成时，图片、视频、音频参考文件统一批量上传到 KK 临时文件接口 `https://video.kkone.vip/api/uploads`，创建请求使用返回的临时公网 URL，不再依赖 `PUBLIC_BASE_URL`。
- [ ] 图片和视频生成完成后，第三方返回地址会先下载保存到服务端 `data/generated-media`，各工作台和画布回显 `/api/media/generated/...` 本地地址；图片任务将该站内地址识别为有效结果，避免第三方临时链接过期或误报“接口没有返回图片”。
- [ ] 管理后台 AI 日志会记录文本、图片、视频请求的最终上游 `requestUrl`，Gemini 日志可见模型所在的 `/models/{model}:generateContent` 路径；列表支持显示、查看和搜索请求地址。URL 中的账号、API Key、Token、密钥与签名参数会脱敏后再写入日志。
- [ ] 画布视频节点双击会在弹窗内播放而非进入浏览器原生全屏；双指滚动或捏合经过视频、全景图、导演台等任意节点时均持续控制画布，且不会触发视口更新循环。
- [ ] 视频创作台固定使用侧边模式；模型下拉仅展示后台模型算力点中配置为视频类型的模型。时长、比例、画质、音频和码率复用画布视频节点的设置样式与后台能力限制，首次进入、新建会话或切换模型时默认使用 `21:9 / 5S / 720P / 高码率`，对应能力不可用时回退后台列表第一项；顶部支持文生视频、图生视频、首尾帧、全能参考和视频续写，素材限制、失效素材保留与生成参数与画布一致。创建任务后保留提示词，生成按钮可继续提交任务；开始生成按钮显示按次或按秒、并结合任务数量计算的积分，历史记录预览和重试会恢复所选视频模式与码率。
- [ ] 生图工作台和视频创作台的提示词输入支持输入 `@` 搜索当前可参与生成的参考图片、视频和音频，选择后插入对应素材编号；切换视频模式时，当前模式不可用的素材不会出现在 `@` 菜单中。
- [ ] 管理后台模型算力点在积分列前支持配置参考图片、参考视频、参考音频数量：图片模型默认可参考 16 张图片，视频模型默认可参考 9 张图片、3 个视频、3 个音频，均可设为 0；文本和音频模型不展示这些字段。画布图片节点、生图工作台会按图片模型的图片参考数限制素材；画布视频节点和视频创作台仅在“全能参考”模式按视频模型三项配置限制上传、素材库引入和生成请求，图生视频、首尾帧、视频续写维持原有限制。超过新上限的画布视频素材保留为禁用状态。
- [ ] 画布图片任务按 90 秒、视频任务按 7 分钟计算从 18% 开始、前快后慢的时间进度；节点展示接口进度与时间进度的较大值，未完成时最多显示 99%，接口失败立即显示失败。图片和视频候选生成中的覆盖层改为全节点透明模糊层上的无缝循环水位填充，只保留进度百分比和耗时。打开历史画布时，会尽力把仍指向第三方的已生成图片、视频迁移到 `/api/media/generated/...`；上游文件已失效时保留原地址，不影响其余节点加载。
- [ ] 画布节点发起生成后自动收起输入配置面板，仅显示节点生成状态；生成期间单击节点可只读查看原提示词和参数，不能修改、上传、删除引用或再次提交。复制或粘贴生成中的节点会清除主任务与候选任务的加载状态和任务 ID，保留已成功内容、提示词及模型参数，副本可直接编辑。
- [ ] 复制画布节点后，若粘贴前左键点击画布空白处，粘贴内容会以该点击处为左上角起点；未点击空白处时仍粘贴到画布中心。
- [ ] 画布节点顶部操作条、模型下拉和各类型设置浮层会随画布缩放；音频设置在画布平移时同步跟随节点。所有画布节点输入面板和配置节点不再展示摄像机按钮，已有摄像机参数仍保持在节点数据中。
- [ ] 指针位于画布节点的标题、文本提示词、配置输入区、顶部操作条及其 Tooltip 时，双指/滚轮仍持续平移画布；平移不会让未变化的普通节点逐帧重渲染。弹窗、下拉菜单与媒体原生控件保持各自原有的滚动行为。
- [ ] 选中画布节点时，所有与其相连的连线会出现唯一的胶囊状高亮脉冲，沿贝塞尔曲线流向当前节点；脉冲到达后短暂停顿并循环，取消节点选择后效果立即消失，多选时每条相关连线按原始方向流动。触控板平移期间暂停连线脉冲和阴影，停止后自动恢复，避免动画造成画布掉帧。
